# P1 – Project Folder and Terminal Navigation

## Aim
To understand basic terminal commands and practise navigating between project directories.

## Commands

```bash
pwd
ls
cd ..
pwd
ls
cd "laboratery project 1 (web dev) 2"
pwd
```

## Description

- `pwd` displays the current working directory.
- `ls` lists files and folders in the current directory.
- `cd ..` moves one directory level back.
- `cd "laboratery project 1 (web dev) 2"` enters the project folder.
- `pwd` verifies the current directory.

## Result
Successfully practised terminal navigation and understood how to locate and access the project directory.
