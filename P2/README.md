# P2 – Portfolio Repository with an Initial Commit

## Aim
To create a Git repository for a portfolio project and save the initial commit.

## Commands

```bash
git init
git status
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/srahul-gif/Web-development-assignment
git push -u origin main
```

## Description

- `git init` initializes a new Git repository.
- `git status` displays the current state of the repository.
- `git add .` stages all project files for committing.
- `git commit -m "Initial commit"` saves the first commit.
- `git branch -M main` renames the current branch to main.
- `git remote add origin` connects the local repository to GitHub.
- `git push -u origin main` uploads the project to GitHub.

## Result
Successfully initialized a Git repository, created the initial commit and uploaded the project to GitHub.
